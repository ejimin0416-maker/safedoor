# SafeDoor 관제

복정고 싹싹복정 발명대회 출품작 SafeDoor의 관제 웹입니다. 소화기함·소화전 앞 적치물을 감지하고 층별 3D 모형, 화재 시뮬레이션, 시제품(오렌지보드 BLE) 실시간 연결을 보여줍니다.

## 파일
- `index.html` : 관제 웹 (GitHub Pages로 여는 파일)
- `lib/` : 3D 라이브러리 (three.js r128, OrbitControls)
- `SafeDoor_local.html` : 인터넷 없이 여는 한 파일짜리 버전
- `SafeDoor_BLE_FastDemo_Reset.ino` : 시제품 아두이노 코드

## 블루투스 연결
https 주소(GitHub Pages)나 PC 크롬에서 열고, FE-01 또는 시뮬 공간에서 "블루투스로 연결"을 누르세요. 안드로이드·PC 크롬에서 동작합니다.

도면과 기록은 예시 데이터를 포함한 근사치입니다.
